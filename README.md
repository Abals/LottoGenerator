# 로또 번호 생성기 (Windows)

## 기능
- **번호 생성**: 지금까지 1등 당첨번호로 나온 조합은 빼고 1~45에서 무작위 생성
- **포함할 번호**: 번호판을 눌러 원하는 번호를 최대 6개 골라 모든 게임에 넣기 (6개를 모두 고르면 그 조합 1게임만 생성)
- **게임 수**: 1~5게임 선택
- **당첨 이력 확인**: 6개 번호를 고르면 과거 1등 번호였는지, 매주 샀다면 몇 등을 몇 번 했을지 표시
- **TOP 6**: 왼쪽에 가장 많이 나온 번호 6개와 출현 비율(%) 표시 (보너스 번호 제외)
- **자동 업데이트**: 토요일 오후 8시 이후 5분마다 동행복권에서 새 회차를 확인해 추가
- **카카오톡 나에게 보내기**: 생성한 번호 전송, 새 회차가 나오면 당첨번호와 내 번호 결과 알림

1~1246회(2026-10-17) 당첨번호가 내장되어 있어서 처음 실행할 때 수천 번 조회하지 않습니다. 이후 회차만 동행복권에서 받아옵니다.

## 실행 방법
Python 3.8 이상이 필요합니다. ([python.org](https://www.python.org/downloads/)에서 설치, 설치 화면에서 "Add python.exe to PATH" 체크)

- **바로 실행**: `run.bat` 더블클릭
- **exe 만들기**: `build.bat` 더블클릭 → `dist\LottoGenerator.exe` 생성. (build.bat은 lotto_app.py와 같은 폴더에 있어야 합니다) 이 exe 하나만 다른 PC에 복사해서 써도 됩니다(그 PC에는 Python 불필요).

> 직접 만든 exe는 서명이 없어서 Windows SmartScreen이 "알 수 없는 앱"이라고 경고할 수 있습니다. "추가 정보 → 실행"을 누르면 됩니다.

> build.bat이 실패하면, 이 폴더 주소창에 `cmd`를 입력해 명령 프롬프트를 열고 아래 두 줄을 실행해도 됩니다.
> ```
> py -m pip install pyinstaller
> py -m PyInstaller --noconfirm --onefile --windowed --name LottoGenerator lotto_app.py
> ```

## 카카오톡 연결 (처음 한 번)
1. [카카오 디벨로퍼스](https://developers.kakao.com)에 로그인 → 애플리케이션 추가
2. 앱의 **REST API 키**를 복사
3. **카카오 로그인**을 사용(ON)으로 설정하고, **Redirect URI**에 `http://localhost:8765/callback` 등록
   (앱의 '카카오톡 설정' 탭에 표시된 주소를 그대로 복사해서 쓰면 됩니다)
4. **동의항목**에서 `카카오톡 메시지 전송(talk_message)`을 선택 동의로 설정
5. 앱의 '카카오톡 설정' 탭에 REST API 키 입력 → **설정 저장** → **카카오 로그인** → 브라우저에서 로그인·동의
6. **테스트 메시지 보내기**로 '나와의 채팅'에 오는지 확인

- 카카오 앱 설정에서 Client Secret을 사용으로 켰다면 그 값도 입력해야 합니다.
- 8765 포트를 다른 프로그램이 쓰면 앱에서 포트를 바꾸고, 카카오 디벨로퍼스의 Redirect URI도 똑같이 바꿔 주세요.
- 로그인은 약 2개월 유지되고, 앱을 쓰는 동안 자동으로 연장됩니다. 오래 안 쓰면 다시 로그인하면 됩니다.
- 메시지 버튼은 동행복권 홈페이지로 연결됩니다. 버튼 링크까지 동작하게 하려면 카카오 앱의 플랫폼(Web) 사이트 도메인에 `https://www.dhlottery.co.kr`을 등록하세요. 등록하지 않아도 메시지는 옵니다.

## 저장 위치와 보안
- 데이터: `%APPDATA%\LottoGenerator\` (추가된 회차, 설정, 마지막 생성 번호)
- REST API 키와 로그인 토큰은 Windows DPAPI로 암호화되어, 같은 PC의 같은 Windows 계정에서만 풀립니다.
- **공용 PC**에서는 쓰고 나서 **로그아웃**을 누르거나 '이 PC에서 카카오 설정 모두 지우기'를 눌러 주세요.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `lotto_app.py` | 화면 (실행 진입점) |
| `lotto_core.py` | 당첨번호 조회·저장, 번호 생성, 이력 확인, 통계 |
| `kakao.py` | 카카오 로그인, 토큰 암호화 저장, 나에게 보내기 |
| `lotto_seed.py` | 1~1246회 당첨번호 |

## 참고
- 당첨번호는 동행복권 조회 주소(`/lt645/selectPstLt645Info.do`)에서 받습니다. 동행복권이 주소나 형식을 바꾸면 업데이트가 실패할 수 있으며, 이때 왼쪽 아래에 오류가 표시됩니다.
- 과거 1등 조합을 빼는 것은 재미 요소일 뿐, 당첨 확률은 모든 조합이 똑같습니다.
